# Integral University Campus Navigator

A modern, mobile-friendly campus navigation system with GPS-powered live tracking.

## Features

### 🗺️ Interactive Campus Map
- Detailed campus layout with all major buildings and landmarks
- Optimized road network for accurate navigation
- Professional dark theme with glassmorphism effects

### 📱 Mobile-First Design
- Responsive design that works perfectly on phones and tablets
- Touch-friendly interface with proper button sizing
- PWA (Progressive Web App) capabilities for offline use
- Installable on mobile devices

### 🧭 GPS Live Navigation
- Real-time GPS tracking to guide you to destinations
- Live direction arrows and distance updates
- Automatic arrival detection
- Mobile navigation panel with turn-by-turn guidance
- Haptic feedback (vibration) on supported devices

### 🎯 Smart Features
- Automatic route calculation using Dijkstra's algorithm
- GPS-based location detection
- Bearing calculation for directional guidance
- Campus boundary detection
- Professional UI with smooth animations

## How to Use

### Desktop
1. Select a start location and destination
2. Click "Navigate" to see the route
3. Use GPS button to mark your current location

### Mobile
1. Install the app (PWA) for best experience
2. Select destination and click GPS button to start live navigation
3. Follow the direction arrows and distance guidance
4. The app will vibrate when you arrive

## Technical Features

- **PWA Ready**: Service worker for offline functionality
- **GPS Integration**: High-accuracy location tracking
- **Responsive Design**: Works on all screen sizes

## Browser Support

- Modern browsers with GPS support
- iOS Safari 13.4+
- Android Chrome 68+
- PWA installation supported on mobile devices

## Installation

1. Open the app in a supported browser
2. On mobile: Tap "Add to Home Screen" or "Install App"
3. The app will work offline once installed

## Privacy

The app only uses GPS location when you explicitly start navigation. Location data is processed locally and never stored or transmitted.
